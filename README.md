# CodeForge

> Open-source local AI coding agent for Windows and Linux.

CodeForge is a desktop development environment built around a simple idea: make coding with AI powerful, private, and local-first.

Built with **Tauri**, **React**, **TypeScript**, and **Rust**.

## ✨ Current Features

- 🖥️ Native desktop application
- ⚛️ React + TypeScript frontend
- 🦀 Rust backend powered by Tauri
- 📁 File and project management foundation
- 📂 File selection and dialog integration
- 🔒 Local-first architecture
- 🚀 Designed for Windows and Linux

### Install

Clone the repository:

```bash
git clone https://github.com/bh3jeuh/codeforge.git
cd codeforge

install dependencies:

npm install

Start the development application:

npm run tauri dev
